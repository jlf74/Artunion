# ART UNION

Полный адаптивный HTML-макет: 38 проектов и 4 общие страницы. Утверждённая тёмно-синяя концепция Cinema.

## Просмотр

Живой макет для клиента: https://jlf74.github.io/Artunion/ — открывается без входа в GitHub. Все 42 страницы, анимации, мобильное меню и переходы между проектами опубликованы через GitHub Pages. Обновления main публикуются автоматически.

Точка входа — `index.html`. Для локального просмотра установите Node.js 18+ и выполните `npm start` в папке репозитория. Откройте http://127.0.0.1:4180/. Установка зависимостей не нужна. Все ссылки относительные, поэтому комплект можно перенести в подкаталог обычного статического хостинга.

## Общая система

- `assets/palette.css` — единая палитра всех 42 страниц: #142349 / #101D3D / #0C1733, акцент #D64841.
- `assets/styles/` — общие CSS, каждый одинаковый блок хранится один раз.
- `assets/scripts/` — общая логика меню, галереи, переходов, анимаций и плееров.
- `assets/media/` — локальные изображения и шрифты Golos Text / Oswald.
- `site-pages.json` — названия и адреса всех страниц.
- `project-*.html` — 38 кейсов с переходом к следующему проекту и ко всем проектам.

На телефоне галерея по умолчанию в одну колонку. Вариант с крупными карточками и малыми попарно: `projects.html?gallery=mixed`.

## Границы макета

Видео Vimeo/YouTube и карта OpenStreetMap требуют интернет. Восемь ранее недоступных Vimeo не запускаются; список и даты проверки — `docs/missing-videos.md`. Повторная проверка доступности всех роликов не выполнялась. Форма демонстрационная: выполняет локальную проверку, но не отправляет данные. Политика конфиденциальности пока без документа. Продуктовые вырезки Даров Кубани и Овсяши — согласованные макетные версии.

Макет опубликован на GitHub Pages и подготовлен для последующего переноса. Подключение формы и окончательная реализация выполняются отдельно. Архивные концепции, переписка и служебные данные в репозиторий не включены.
