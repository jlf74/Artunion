Проект

Groupe SEB

Задачи

  • Увеличение продаж «Tefal» и продукции других брендов.
  • Создание нового Landing Page для «Tefal Optigrill».
  • Разработка мультибрендового баннера для проведения акции.

Барьеры

Устаревший дизайн Landing Page + сложная навигация, большая линейка «Optigrill», растиражированный другими рекламный образ Константина Ивлева. Мультибрендовый баннер – разные по формату и масштабу предметы, закон «О рекламе» стимулирующих мероприятий.

Решение

Создание Landing Page с акцентом на новой модели «Elite Optigrill». Сравнить и выбрать другие модели удобно с помощью таблиц. Мы решили не использовать изображение Константина Ивлева на главном экране и разместили видео с ним в рубрике «Рецепты». Для гармоничного расположения всей информации на мультибаннере мы разделили его на секторы и сделали макет в соответствии с фирменным стилем компании.
